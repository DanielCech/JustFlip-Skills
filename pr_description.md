This PR adds subject-aware interest icon selection to the JustFlip flashcard creation skill. Generated decks can now carry an SF Symbol chosen from the same curated catalog shown in the app’s Create/Edit Interest picker.

## Changes

- Added the complete 339-symbol interest icon catalog and semantic suggestion guidance.
- Added `interest_icon` to the documented content schema and generation workflow.
- Added `--interest-icon` support to the CSV/TSV/pipe converter.
