# JustFlip interest icon catalog

These are the exact SF Symbol names currently exposed by the JustFlip
Create Interest / Edit Interest picker (InterestIconCatalog.curatedSymbols).
Use the symbol name in the top-level `interest_icon` JSON field.

When suggesting an icon, match the subject semantically and prefer a filled or
distinctive symbol when both variants are available. Useful starting points
include:

| Subject | Good suggestions |
| --- | --- |
| Learning, study, books | `book.closed`, `books.vertical.fill`, `graduationcap`, `brain.head.profile` |
| Languages, writing | `character.book.closed`, `text.bubble`, `pencil.and.outline`, `globe` |
| Science, medicine | `atom`, `stethoscope`, `cross.case.fill`, `waveform.path.ecg` |
| Music | `music.note.list`, `guitars`, `pianokeys`, `metronome.fill` |
| Programming, technology | `swift`, `curlybraces`, `terminal`, `laptopcomputer` |
| Geography, travel | `globe`, `map`, `airplane`, `mountain.2` |
| Sports, fitness | `figure.run`, `dumbbell`, `sportscourt`, `basketball` |
| Art, theatre, media | `paintpalette`, `theatermasks`, `camera`, `film` |
| Food, everyday topics | `fork.knife`, `cup.and.saucer`, `house.fill`, `pawprint` |
